# LIY學生數字素養計劃｜入門階段

中華傳道會李賢堯紀念中學學生 AI 素養學習站。本版本供校內同事檢視學生指引、情境練習、自我檢查、課業聲明及入門階段證書流程。

**網址：** <https://ccp-liymss.github.io/liy-ai-literacy/>

**目前狀態：** 學習內容可供檢視；正式測驗、證書寄送及學生完成紀錄尚未開放。正式政策及個人資料安排仍待校內確認。

## 請同事協助檢視

- 指引是否清楚說明先想、查證、申報、有疑問便問，以及紅、黃、綠三燈的界線。
- 8 題校園情境的答案、即時解說及指引連結是否恰當。
- 自我檢查在「開始使用前」及「使用後／提交前」是否給出合適的下一步。
- 聲明工具的必填欄位、中英固定句式及未完成查證提示是否清楚。
- 證書流程及完成數統計說明是否準確。

GitHub Pages 網址沒有登入限制；任何取得網址的人都能開啟。頁面已要求搜尋引擎不要索引，但這不會限制存取。請勿在頁面或回饋中輸入可識別學生的資料。

## 入門階段證書流程

1. 學生閱讀指引、完成情境練習並使用自我檢查。
2. 正式開放後，以 `@gl.liymss.edu.hk` 學校 Google 帳戶應考；每次 10 題，涵蓋 5 個學習範疇，答對 8 題或以上為合格，可重考。
3. 合格後電郵發送圖片證書，列有證書姓名、日期及獨一無二的證書編號。未有名冊配對資料時，通過者須自行填寫證書姓名。
4. 按學校帳戶去重計算完成人次。日後匯入全體學生名單後，管理員可配對既有紀錄並按學生及班別分析；名單匯入前的數字可能包括教職員。

管理員已使用獨立測試資料檢查測驗、證書圖片電郵及完成紀錄流程；此測試不計入正式完成數。正式測驗目前仍保持關閉，校內同事可先檢視網站中的學習內容及流程說明。如需同事實際試考及收測試證書，管理員須先設定個別教職員測試帳戶。由於學生與教職員共用學校網域，不能單憑網域限制把測試只開放給同事。

## 頁面資料處理

學習練習及聲明文字只在目前頁面處理，不會傳送到 AI 服務或測驗資料庫；重新整理或按「清除本次所有答案與表格」後清空。正式測驗開放後，校方系統會保存學校帳戶、已提交的作答、分數、合格狀態、證書姓名、編號及寄送狀態，以支援完成統計和跟進。實際開放前仍須確認資料保存及管理安排。

## 網站維護

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站入口及搜尋索引設定 |
| `site-config.js` | 測驗開放狀態及測驗入口 |
| `content.js` | 中英指引內容、三燈、四習慣及 8 題情境 |
| `app.js` | 導覽、自查、聲明、語言切換及重設功能 |
| `styles.css` | 桌面、手機、平板及列印排版 |
| `assets/mark.svg` | 本站圖示 |

網站內容修訂須同步檢查中英文、情境解說、自查分支及聲明固定句式。正式測驗按鈕受 `site-config.js` 的核定狀態控制；不得把網站設定為已核定，除非校方完成政策審議並確認測驗、證書及資料管理安排。
