# LIY學生數字素養計劃｜入門階段

中華傳道會李賢堯紀念中學學生人工智能素養學習站，協助學生練習「先想、查證、申報、有疑問便問」，並認識任務的綠、黃、紅三色使用界線。

**學生指引版本：** v270926

**網站：** https://ccp-liymss.github.io/liy-ai-literacy/

## 入門階段

學生閱讀指引、完成情境練習及快速自查，再以學校 Google 帳戶登入完成指定測驗。每次測驗共 10 題，涵蓋 5 個學習範疇；答對 8 題或以上為合格。合格後，系統會以名冊姓名或頁面提示所填姓名製作圖片證書，列有日期及獨一無二的證書編號，並寄至學校電郵。

學校以帳戶統計不重複完成人次。名冊供管理員配對及按學生、班別跟進；名冊不是登入或應考門檻。測驗入口開放後，請按校內通知登入。

## 安全使用

請勿在互動欄位填入敏感、機密或他人資料。正式測驗系統會保存學校帳戶、已提交作答、分數、證書姓名及編號、寄送狀態，以支援完成統計和跟進；資料保存期限按校方安排執行。

## 網站檔案

- index.html：網站入口及搜尋索引設定
- site-config.js：指引版本、測驗入口狀態及連結
- content.js：中英指引內容、三色框架、四個習慣及 8 題情境
- app.js：導覽、自查、課業聲明、語言切換及重設功能
- styles.css：桌面、手機、平板及列印排版
- assets/mark.svg：網站圖示

修訂指引後，請同步核對中英文、練習解說、自查分支及課業聲明固定句式。
