# AI 學習有方｜學生 AI 素養學習站

中華傳道會李賢堯紀念中學學生學習試用版，依據《校本人工智能學習與使用指引》稿 v1 整理。網站不是已獲批准的正式政策，英文為中文初稿的輔助翻譯。

## 開啟使用

解壓縮整個資料夾，雙擊 `index.html` 即可使用。請保留資料夾結構。免安裝、免登入，毋須接駁 AI 服務。

正式 GitHub Pages 網址：`https://ccp-liymss.github.io/liy-ai-literacy/`。本機亦可直接開啟 `index.html`，毋須啟動伺服器。

## 學生可以做甚麼

- **讀懂指引**：探索「先想、查證、申報、有疑問便問」四個習慣，以及紅、黃、綠三燈；閱讀私隱、知識產權、查證及誠實使用提醒。
- **情境練習**：8 題校園情境，答題後立即看解說及相關指引；完成後可逐題回顧或重做。
- **快速自查**：分「開始使用前」及「使用後／提交前」，按答案提供具體下一步，另設資料安全問題。
- **課業聲明**：按實際使用填寫工具、協助、自己的工作及查證情況，整理成中文或英文聲明，可複製、下載 TXT、列印或另存 PDF。

切換中英語言會保留本次答案及輸入，只翻譯介面及固定句式，不翻譯學生自行輸入的文字。四燈／五問的早期構思已由這份新稿的三燈／四習慣取代。

## 課堂使用建議

教師先說明這次課業的燈號、可用範圍及申報要求，再讓學生探索相關內容。可先獨立完成情境練習，再討論「同樣的功能，為何在不同任務有不同界線」。學生開始使用 AI 前做一次自查，提交前再按實際情況檢查，需要申報時才整理聲明。

自查不會給予使用許可或保證合規。黃燈須有教師明確批准，申報及紀錄要求依教師或科組安排；填寫聲明不能令違規使用變成獲准。

## 共用裝置與保存

答案、分數和表格只保存在本次頁面的記憶體，不寫入瀏覽器儲存空間、不上傳、不使用追蹤程式。重新整理後清空；切換站內頁面會保留。頁尾的「清除本次所有答案與表格」可一次重設，個別工具也有自己的清除／重做按鈕。

需要保留聲明時，請先自行複製、下載或列印。若瀏覽器不容許自動複製，工具會選取文字，提示手動複製。共用裝置上自行下載或列印的檔案，須另外處理。
